# ФільтрОК / FiltrOK

Сайт застосунку ФільтрОК на GitHub Pages (українською й англійською, перемикач UA/EN):

- `index.html` — головна сторінка;
- `privacy.html` — політика конфіденційності: https://yarnix-sketch.github.io/filtrok/privacy.html
- `terms.html` — умови використання (публічна оферта): https://yarnix-sketch.github.io/filtrok/terms.html

Спільні стилі в `style.css`, перемикач мови в `lang.js`. Код застосунку лежить в окремому приватному репозиторії.
